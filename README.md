# Hikari Hasegawa

### Building software that belongs to its users.

Hikari Hasegawa is an independent open-source software initiative focused on building **free, useful and transparent software** designed around user ownership.

The goal is simple:

> **Technology should serve people, not monetize them.**

Projects are built with a **local-first and privacy-first philosophy**, avoiding unnecessary cloud dependencies, advertising, subscriptions, paywalls and data collection.

AI is used as a development multiplier — not as a replacement for engineering judgment.

Every project aims to be:

* **Free to use**
* **Open Source**
* **Privacy-first**
* **Local-first whenever possible**
* **Transparent and auditable**
* **Without ads or forced accounts**
* **Without artificial “Pro” limitations**

The long-term goal is to release **a new open-source software project approximately every month**, tackling real problems that are too often solved through subscriptions, invasive data collection or unnecessary cloud services.

### Current projects

* **VersoCon** — local, offline and open-source file conversion.
* More projects are currently being developed.

### The philosophy

AI can dramatically increase how much software one developer can build.

But generating code is not the same as engineering software.

The developer remains responsible for architecture, security, verification, maintainability and the decisions behind the code.

**Build more. Give more. Own your technology.**
